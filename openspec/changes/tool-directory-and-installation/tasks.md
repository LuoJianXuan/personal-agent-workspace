## 验收清单（执行结果以 TC-VERIFY 为准）

1. 普通用户在工具页查询真实目录；搜索/分类标签切换；平台 MCP 不要求个人 Token。
2. 麦当劳安装：无效 Token → 明确错误；有效 Token → 发现清单 → 取消无授权；确认后已安装。
3. 已安装的 Token 失效仍留在已安装视图；重新授权恢复。工具更新取消不扩大授权。
4. 卸载删除工作区凭据并撤销后续使用；历史不删除；服务方 Token 不被声称已撤销。
5. 两账号隔离、平台下架、并发版本冲突、远端超时/离线安全失败。
6. Skill 启停、正文、依赖提示；去使用选择该 Skill；缺失依赖遵守现有后端拦截。
7. 浏览器从对话内安装/取消/失败，草稿不丢失；从目录去对话只填写草稿，显式发送才运行。
8. 真实 DeepSeek + 麦当劳只读活动查询、既有写审批 Mock、Tavily/文档/产物回归。
9. 桌面与窄屏、键盘焦点、错误态、旧路由；管理员更新展示信息在用户目录生效。
