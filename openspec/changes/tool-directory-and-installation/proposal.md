# 工具目录与个人 MCP 安装体验

用户已确认独立 HTML 原型，并授权按该方案实施。目标是统一工具入口与安装体验，复用现有个人连接、凭据、审批与 Harness，不增加 Agent loop 或常驻服务。

## 用户任务与结果

- 工具栏目分 Skill / MCP，支持搜索与全部 / 已启用（已安装）视图。
- 个人 MCP：查看详情 → Token 验证与发现 → 明确授权 → 安装完成 → 回到对话。平台 MCP 标明平台提供，无需个人 Token。
- 管理个人 MCP：检查更新、更换 Token、重新授权、卸载。安装状态与远端即时健康分开描述。
- 技能：查看说明及正文、启停、查看依赖、去对话；不因为启用 Skill 而扩大权限。
- 原型占位服务及虚构技能不进入正式数据。旧路由兼容跳转；模型和运行环境状态移至设置，组合检查收进诊断。

## 边界

保留 Backend / Runtime / Web 进程边界；不改模型调用、工具执行、canonical events、Langfuse、审批策略。新增 Backend 展示元数据与只读平台 MCP 目录，前端共用授权弹窗。保持“当前兼容能力”默认选项和“仅查询”选择，确认前不安装、不执行业务工具。平台安全准入、用户授权和写审批保持原有裁决。

不做开放商城、任意服务 URL/Header、OAuth、STDIO、安装包、技能编辑器。管理员编辑名称、简介、分类、图标、Token 帮助链接，部署配置仍决定 endpoint 与安全策略。展示信息不放任何秘密；帮助链接只作浏览器导航，不由服务器抓取。

新增 Backend schema 10 展示元数据列，原授权和凭据不迁移。重新构建 Backend / Web 并发布本地 5173；Runtime 无需改变执行代码。依照 AGENTS.md 默认不运行测试、浏览器自动化或真实模型/MCP 调用。构建和服务启动与业务验收分别记录。
