# S05：资料库、产物、CSV 场景与全页面集成

时间：D5。前置：S04。

## 目标
完成参考网站模式中的资料输入、对话使用、结果交付；首版所有范围内功能代码齐备。

## 实施任务
- Backend 实现 TXT/MD/CSV 上传与元数据、搜索/来源筛选、预览、下载；稳定 file_id，owner 校验，固定存储根与限额。
- 文件原子写临时路径后发布；元数据失败不 READY，孤儿文件清理可解释。Runtime 只通过内部授权 file_id API 读取。
- Web 上传按钮、资料选择器、/app/library 与对话 file_refs；刷新不重复上传/发任务。
- Runtime 注册 read_material 与 csv_summary 固定工具，限制输入/输出。CSV 不用模型计算，输出可核查聚合数据。
- /app/scenes/data-analysis 选文件/列/聚合/图型，复用 Run 管线；ECharts 渲染结构化 chart JSON，不执行模型代码。
- Backend 保存 Runtime 受控提交的图表/CSV 产物；Runtime 在确认 READY 后写 artifact.ready；前台产物面板接真实列表。
- 用户显式导出 Markdown：Backend 请求 Runtime 基于最终结果生成内容，再走内部 artifact 存储；同 run/格式幂等。
- 终态后导出刷新报告 API，不依赖旧 SSE；下载鉴权，报告文件缺失明确报错。
- 管理运行记录与审计页面完成，正文/文件不因 admin 自动越权；跨端导航、空/错误/等待状态全部接入。
- 检查移除 S03 临时审批收敛、MCP 本地假 provider、UI 假数据残留。

## 完成与验收条件
- 上传资料能被选入对话并引用；不支持格式/超限明确拒绝。
- CSV 图表数值来自固定计算结果，显示来源和口径；正常对话仍可用。
- Markdown 真文件、重复导出一个索引、其他用户不能下载。
- 生成产物失败与业务成功分别呈现，不冒充 READY。
- 三端首版页面齐全；A19–A23/A25 验证入口准备完。
