# S07：交付收尾与演示

时间：D7。前置：S06。

## 目标
冻结功能，修完核心失败，形成可重复启动与展示的个人工程项目。

## 实施任务
- 修复首版剩余问题；不增加多 Agent、长期记忆、计费、新格式或新 provider。
- README 写明前后台入口、组件职责、依赖、环境变量、迁移、seed、开发/Compose/Windows 命令、密码配置方式。
- 交付 .env.example 无秘密、锁文件、合成 fixtures、Makefile、PowerShell 脚本；说明 checkpoint/文件卷持久化。
- 新环境验证仅在授权后执行；记录未安装/未验证的部署步骤，不用本机残留证明可复现。
- 整理五段演示与状态图、一次审批时序、一次配置生效链路。
- 提供最终交付清单：代码齐备项、Mock 通过项、真实模型通过项、失败与局限、后续可选功能。
- 简历候选描述只写实际本人决策/AI协作/验收事实，不借用公司规模或参考网站的能力成绩。
- 与用户做一次最多20分钟整条链路说明，不把学习问答当交付审批门槛。

## 完成与验收条件
- Web、Backend、Runtime 三者可明确指认；后台配置真实影响前台与运行。
- 核心缺陷未修不能写全完成；当前模式与验收等级醒目标明。
- 单实例、受控工具、有限恢复、无任意代码执行等边界清楚。
- 交付包不含参考网站密码、公司数据或真实 provider key。

## 交付记录
更新 TASKS.md、docs/evidence/S07.md；列出真实文件、接口、迁移、已执行动作、未执行验证、下一任务接入点。所有代码由 AI 编写。

## 随实现讲解
演示从管理配置到对话执行、审批与产物；能解释一个崩溃窗口和一个不能保证的边界。

## 可直接下发
阅读共同规则、架构、契约和 UI_SPEC，核对前置后只完成本 S07。保持独立三端与冻结首版范围，不主动启动子代理。默认不执行测试或真实模型，准备验收入口并标明状态；已明确授权的动作按原范围继续。不要要求用户手写，不以讲解阻塞下一阶段。
