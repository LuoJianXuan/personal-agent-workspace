# 首版页面与交互

## 用户工作区 /app
桌面：左侧会话与导航、中间对话、右侧可收起产物面板。窄屏侧栏用真实抽屉，必须能看见菜单，不能只出现遮罩。
导航：新对话、近期会话、技能、资料库、场景、个人信息；管理员额外有“管理控制台”。

### /app/chat 与 /app/chat/:thread_id
顶部标题/改名，中央用户/助手消息，底部多行输入、上传、资料选择、技能选择、模型下拉、发送/停止。
每轮记录实际模型/Skill revision；切换只影响后续 Run，恢复原 Run 不替换配置。
助手正文必须边生成边显示，按 message_id/chunk_index 拼接并按事件去重；completed 用全文替换草稿，不追加第二份。刷新后按契约重建运行正文，断线显示重连状态；失败/取消时保留草稿并标“未完成”。不显示隐藏推理或工具参数碎片，不用全文返回后的打字动画冒充流式。渲染可节流，不要求每个 token 重绘 Markdown。
工具卡片显示名称、脱敏参数、REQUESTED/RUNNING/完成/失败。审批卡显示完整非敏感业务参数、期限、批准/拒绝与操作结果；不能仅展示一句“允许吗”。
WAITING_APPROVAL 显示恢复/审批；INTERRUPTED 显示结果与重新发起提示，不承诺随意续跑。
刷新只 GET 历史/重连；不自动 POST 新运行。不隐藏失败，不静默换 Mock。
发送需要固定本次 HTTP 幂等键，失败重试使用同一键；用户明确修改输入属于新请求。
状态包含：未配置模型、无技能、MCP 不可用、网络中断、排队、运行、待确认、取消请求中、已完成、失败。
Markdown 禁止原始 HTML 注入；工具文本与附件内容只作数据展示。模型隐藏推理不展示。

### /app/skills
卡片/列表、分类与搜索、正文只读详情、个人启停。管理员编辑走 /admin/skills；普通用户不能改变平台正文。
不展示“个人技能自动进化”等未实现开关。

### /app/library
上传 TXT/MD/CSV，文件名搜索、上传/生成来源筛选、大小/类型/时间/来源会话，详情纯文本预览、下载、用于对话。
无权限返回统一不可见；未 READY 文件不能被选择。文件失败显示原因。
右侧产物面板复用相同文件详情组件，展示本 Run 的 Markdown 报告/CSV/图表 JSON。

### /app/scenes/data-analysis
单一 CSV 分析入口：选择文件、维度列、数值列、聚合与图类型，填写问题，进入共享对话。
图表来自计算后的受校验 JSON；展示数据来源、单位（用户可选填）、聚合口径与行数。模型文字不能替代数值结果。
只显示可用场景，不铺五个不可点击的“筹备中”入口。

### /app/profile
用户名、角色、退出。没有计费点数/企业加入/记忆热力图。登录页面明确 demo 账号性质，不把密码写在公共源码里。

## 管理控制台 /admin
左侧导航：模型、技能、MCP、用户、运行记录、审计。顶部可返回工作区。
前端路由守卫只是体验，所有管理 API 后端检查管理员角色。

| 路由 | 列表与表单 | 必须可验证的交互 |
| --- | --- | --- |
| /admin/models | 名称、支持的协议、模型 ID、可选平台标签、受控协议选项、URL、凭据别名、上下文/输出上限、能力、默认、启停；首版思考模式固定关闭 | 按决策 005 实现；保存后目录同步；密钥不回显；分别显示配置、凭据、chat/stream/tool_loop 验证状态；未实现的协议不可选 |
| /admin/skills | 名称、描述、分类、Markdown 正文、revision、启停 | 新增后用户可见；编辑增加 revision；普通用户无写权限 |
| /admin/mcp | 连接名称、允许地址、凭据别名、状态、最近探测 | 发现工具列表与 schema；逐工具启停；发现不自动授权 |
| /admin/users | 账号、角色、启用状态；新增普通用户 | 禁用后权限生效；不能禁用唯一管理员 |
| /admin/runs | run_id、owner ID、状态、模型、起止时间、安全错误 | 请求级追踪；详情敏感数据按 owner 控制；不可任意修改运行状态 |
| /admin/audit | 操作者、动作、对象、时间、结果、request_id | 可按对象/时间基础筛选，不输出凭据和完整私有正文 |

统一 Loading/Empty/Error、保存中禁重复提交、失败保留输入、成功刷新真实列表；不用前端假数据覆盖 API 失败。
