## 必须实现的具体边界

### 对话流式体验
首版必须具备真实回答正文增量、工具/审批进度和最终消息收敛，链路为模型 → Runtime → Backend → Web。SSE 是承载事件的传输方式，不自动等于正文逐步输出；不以一次性全文加打字动画验收。按短窗口合并文本块并持久化补读，不要求一个汉字/token 对应一个事件，也不展示隐藏推理。此项纳入 D3，不增加独立网关或延长为多周计划。

### 模型
模型接入按 [决策 005](../decisions/005-model-access.md) 在 S02/S03 落实：DeepSeek 为首个实现与真实验收目标；首版支持文本、真实流式与非思考模式工具调用。管理员维护名称、协议 protocol、可选平台标识 provider、受控 protocol_options、provider_model_name、base_url、credential_ref、上下文/输出上限、能力声明、启停与默认项。首版仅实现 openai_chat_completions 协议，可配置多个兼容模型；按协议选择适配器，平台仅作展示或配置预设，其他原生协议预留适配入口，不宣称已支持或已验证。不做多渠道自动路由。
密钥由部署环境提供，网页只选择已部署的凭据别名、展示配置是否存在，不提供明文密钥读取；修改密钥通过本项目部署配置，不虚构网页密钥管理能力。
管理员改变 default 或 enabled 后，新运行即时采用。关闭最后一个可用模型允许保存，但新真实运行明确失败 MODEL_UNAVAILABLE；Mock 不伪装为真实模型。
连接探测分为本地配置检查与真实模型调用；后者消耗额度，只在明确授权范围执行。

### Skill
管理员新增名称、描述、分类和 Markdown 正文，编辑、启停；每次变更 revision。用户浏览搜索平台技能并管理个人启用偏好，每轮最多选择 3 个。
选中已禁用/未授权 Skill 返回明确错误，不静默忽略；未选中时默认使用用户已启用的最多 3 个，超过限制要求明确选择。
正文是指令，不授予工具权限。首版没有 ZIP 上传/脚本安装、个人技能自动创建、技能自动进化。

### MCP
管理员新增连接名、Streamable HTTP 地址、可选凭据别名，编辑、禁用、探测/发现、查看工具 schema、逐工具启停。
地址必须符合部署的 origin/path 白名单。演示 Compose 允许唯一 demo-mcp 内网地址；可新增多个白名单内连接，不接受任意网段、任意重定向或 stdio 安装。
发现的工具默认禁用，管理员明确启用后才进入新运行；仅允许部署清单标为只读的远端工具。MCP 的只读注解不能代替信任与准入决策。
真实 MCP 写工具不在首版；写审批由自建 create_demo_ticket 演示，避免外部写入无法核查。
连接探测经 Runtime MCP 客户端完成初始化与 list_tools，不执行业务工具；页面分别显示连接配置状态、最近探测状态与时间。

### 文件与资料库
先支持 UTF-8 TXT、Markdown、CSV。每文件不超过 5 MB，每轮最多 3 个；文本抽取最多 50,000 字符，CSV 最多 10,000 行/30 列。超限明确错误，不静默截断后给完整分析结论。
上传、列表、搜索文件名、按上传/生成来源筛选、纯文本预览、下载、用于下一轮对话。元数据保存来源 run_id、类型、大小、hash、owner、READY/FAILED 等状态。
首版不做 PDF/Office/OCR、向量检索、收藏、标签、目录、回收站。界面显示支持格式；资料库不称为完整知识库。
模型只能通过受控 file_id 读取授权内容；禁止任意磁盘路径和远端 URL。

### 对话与场景
通用聊天，真实模型决定是否调用工具；Mock 只替换模型决策层。
会话列表、改名、历史消息、每轮模型/技能、工具调用卡片、审批、停止、错误、重连、最终答案。
场景只有“CSV 数据分析”一个可执行入口，复用同一聊天/Run 管线。用户选择 CSV、维度列、数值列、sum/count/avg 与 bar/line；固定工具计算，前端 ECharts 展示校验后的图表 JSON。最多 50 个分组，超过时拒绝或要求用户缩小，不静默遗漏。无任意 Python/JS 执行。
保留通用对话入口，禁止强迫全部任务走订单模板。
工单案例：通过只读 MCP 查演示订单 → 提议建单 → 人工确认 → 幂等建单 → Markdown 报告。
报告由持久化结构化结果生成，不增加第二个模型。产物失败不篡改业务 Run 成功状态。

### 用户与管理
固定一个 demo 租户/项目；三份演示身份：管理员、用户 A、用户 B。管理员可创建普通用户和禁用用户；不做注册、重置密码、企业创建/加入、角色树、计费、SSO。
管理配置只有管理员可写。聊天、文件、审批始终检查归属；管理员首版也不自动获得读取其他用户正文/文件的权力。运行管理默认显示全局脱敏元数据，正文仍按 owner 校验。
禁用用户使后续请求和工具授权检查失败；不承诺追溯撤回已提交的副作用。

## 不能为赶工删除的能力
独立 Backend/Runtime、可操作管理界面、真正模型调用适配、真实 MCP、归属检查、审批、幂等、等待点恢复、文件上传下载、前后台配置生效链路。

## 明确不做
桌面/Tauri、独立 BFF、独立网关进程、NewApi 部署、Redis/持久队列平台、K8s、多副本、任意代码沙箱、多 Agent、长期记忆自动学习、计费、复杂租户、媒体生成、商城。
逻辑工具网关与模型适配边界仍保留。此处是个人项目裁剪，不修改灵机 AI 原仓库的架构约束。

## 截止期控制
先取消动画、主题切换、热力图、复杂表格筛选等装饰；不临时扩大支持文件格式与 provider。
发现首版核心项未完成，记录具体阻塞/失败，继续在 D6–D7 修复；不得悄悄删验收项、用 Mock 冒充真实链路、改为单体或把周期重新排成数周。
