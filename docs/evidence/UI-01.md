# UI-01：工作台交互与版本下载

日期：2026-11-16。实现：代码齐备。验证：构建、业务 API 与浏览器视觉通过。

## 改动与契约

版本列表选择、下载所选版本、来源会话、基于版本继续加工；修复同一Chat页面query变化不更新fileIds；Backend资料列表按逻辑产物当前revision展示。

新增工作台交互基线：

- plan/task 事件合并为单张计划卡，显示进度和逐项状态。
- 最终回答末尾的受限 `clarification` JSON 投影为结构化追问卡；选择只回填输入框，不自动发送。
- MCP、搜索、沙箱、超时和通用工具错误按类型展示可执行的恢复建议。
- 普通用户能力页同时显示模型、技能、工具和运行环境状态；不把未配置能力伪装成可用。

涉及：apps/web/src/phase1.tsx、delivery.tsx、api.ts、chat.tsx。

## 一条请求

版本选择 → chosen File ID → 下载/新对话文件引用 → 新revision。

## 失败边界

版本请求失败可见，不静默取最新；结构化追问解析失败时保留普通最终回答；工具失败不吞掉稳定错误码，也不把未知错误误报为超时。

## 已执行证据

TypeScript/Vite 生产构建通过；版本列表、选定 revision、继续加工、LocalFS/MinIO 下载定位均通过 API 业务验收；正式 5173 返回 200。

浏览器实际验收：

- 管理端 `/admin/mcp`：连接状态、发现时间、部署准入、每次审批与启用状态均可见。
- 普通用户 `/app/capabilities`：`now-time-info` 与三类运行环境状态可见，浏览器 console error 为 0。
- 390×844：能力页和 `/app/chat` 无横向溢出，输入区、导航入口与能力卡仍可访问。
- 浏览器过程没有发送消息、调用模型、执行工具或修改控制面配置。
