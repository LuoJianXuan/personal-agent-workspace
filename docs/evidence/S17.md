# S17 — Runtime 内按需受限解析

状态：代码齐备；真实本地文件/子进程/数据库验证通过。日期：2026-11-06。

Runtime 新增固定入口 `execution.py`、`document_cli.py`、`document_tools.py`：一个活动解析子进程、最多四个等待者、5 MiB 输入、2 MiB 输出、35 秒 wall timeout，Linux 子进程限制 30 秒 CPU/512 MiB，环境变量白名单且不接受 shell。`MaterialTools`、`WorkspaceBackend /inputs` 与显式预览共用同一提取和缓存实现；原始二进制不能通过文字视图下载冒充。

Backend 上传二进制只标记 `not_extracted`；首次 POST 校验 owner/blob/hash 后调用 Runtime，按 file/hash/parser revision 比较写入；再次 POST 命中同一缓存且 `updated_at` 不变。实际 DOCX、文字 PDF、基础 XLSX 解析与定位通过；旧 DOC、原生 WPS、PPT 明确拒绝。

失败验证实际启动了 401,209 字节 XLSX 解析子进程：取消后 kill+wait，超时后释放唯一 slot，最终残留进程为 0；凭据不在子进程环境。外用户读取 parsed/source 返回 404。
