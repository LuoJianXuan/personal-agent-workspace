## 成功与失败链路

提交 → Backend 冻结快照 → Runtime 图执行 → 工具网关 → 审批等待/固定文件工具 → 权威 Backend 写入 → canonical events → UI 投影。

失败不会降级 Mock 或伪造下载。未授权文件被拒绝；配置撤销/过期释放等待；不明写入显示 UNKNOWN；文件存储失败不产生 READY 索引。仅可证明的等待点可恢复，其他崩溃明确 INTERRUPTED。
