# S18 — 内置文档技能与产物闭环

状态：代码齐备；实际 Harness/文件/产物验证通过。日期：2026-11-06。

新增项目维护的 `documents` 技能包（SKILL、formats reference、report template）。每个 Run 在 `runtime.run_skill_bindings` 冻结 version/hash/files；系统提示只装配名称、描述、路径、版本和 hash，正文通过 `/skills/documents/...` 按需读取。技能路径只读，声明不扩张工具权限。

实际 DeepAgents Mock 运行验证：普通系统提示不含技能全文，文档任务通过 `read_file` 读取 `SKILL.md`，绑定版本为 `documents-1`，写入技能路径返回 `WORKFILE_READ_ONLY`。两份 DOCX 比较继续产出带来源 Markdown/DOCX；v2 关联 v1，原件未覆盖，跨用户读取拒绝。

限制：没有技能市场、外部脚本自动安装、扫描 OCR、旧 Office/WPS/PPT、多 Agent 文档专员。Mock 只替换模型输出，文件、工具、数据库和产物均为真实模块。

证据：[定向结果](personal-agent-results.json)、[文档集成](phase1-integration-results.json)、[深度结果](phase1-depth-results.json)。
