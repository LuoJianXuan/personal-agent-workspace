## 完成功能

- Backend 会话创建/列表/改名、消息历史、提交幂等、单会话活跃约束、持久派发、后台终态投影；用户只可读取自己的会话、运行和事件。
- Runtime 真实 LangGraph 模型→工具→模型图，PostgreSQL checkpointer，run_id 作为 graph_thread_id；4 个执行 worker、32 条持久等待队列，CAS/行锁争抢执行权。
- 协议注册表只根据 openai_chat_completions 选择适配器；平台标签不参与选择。DeepSeek 非思考模式已接入。没有验证其他供应商。
- 正文真实流式输出，按 100ms/1KiB 缓冲目标持久化；每 Run 原子分配 seq；Backend 代理 SSE，浏览器按游标补读、去重，用 message.completed 全文收敛。隐藏推理和工具参数增量不进入正文。
- ToolGatewayService 统一检查工具名、参数 schema、部署目标只读许可、提交/快照归属与配置版本；真实 MCP SDK call_tool，20 秒进程级超时。写工具未开放，不能绕过授权。
- 模型调用和每次工具执行前复核 Backend 权威快照；执行快照必须绑定 active submission/run。配置变更失败关闭执行；已发出的外部请求不能追溯撤销。
- 运行失败保留未完成草稿；Runtime 重启把孤立 QUEUED/RUNNING 收敛为 INTERRUPTED，不重放模型或工具。S04 再实现审批等待恢复和取消。
- 管理员运行列表/按 run_id 查询只显示脱敏元数据，不展示他人的私有输入/正文。
- Web 会话列表、多轮消息、模型/技能选择、工具状态卡、Markdown（不执行 HTML，不加载远程图片）、历史过程查看、失败展示。

## 修复的问题

- Runtime 离线时，原快照解析因凭据存在性查询不可达而提前拒绝提交。现仅对内部提交路径允许延后运行可用性核验，保存原命令；执行前仍完整复核，不放宽部署准入。
- 浏览器状态落后于实时正文：接流前查询当前状态，run.started 更新状态并清除过期不可达提示。
- 查看旧轮过程时，正文顺序与历史不一致：按用户轮次原位置渲染选中 Run 的事件投影。
- Gin Writer 不能保证 ResponseController 的写超时可用：通过 HTTP ConnContext 对真实连接设置 10 秒写期限，结束后清除。
